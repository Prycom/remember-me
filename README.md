# remember-me

Убийца Discord в терминале. Голос, групповые комнаты, чат и файлы — на Rust, со своим сервером и без аккаунтов.

## Возможности

- Личные звонки напрямую или комнаты до 16 участников через UDP-сервер.
- Шифрование звонка между клиентами; ретранслятор пересылает зашифрованные пакеты.
- Голосовая активация и push-to-talk, усиление микрофона, автоматическое выравнивание громкости, опциональные шумодав и фильтр голоса.
- VOX сохраняет до 60 мс начала реплики. Обработка тихих коротких ответов учитывает речевой сигнал и адаптируется к фоновому шуму.
- Список участников с никами, состоянием микрофона и звука, индикатором речи и пингом.
- Чат с историей, прокруткой и ссылками, открывающимися в браузере.
- Передача файлов только тем участникам, которые согласились скачать. Предложение действует две минуты.
- Просмотр изображений, GIF и текстовых файлов в терминале или внешнем приложении. Вставка картинок из буфера обмена.
- Пиксельные и ASCII-аватарки, выбор детализации, полноцветный режим и круглая форма.
- Настройки во время звонка, сборки для Linux и Windows, встроенное обновление.

## Скачать и запустить

Готовые сборки: [Linux](https://github.com/Prycom/remember-me/releases/download/test/remember-me), [Windows x64](https://github.com/Prycom/remember-me/releases/download/test/remember-me.exe), [сервер Linux x64](https://github.com/Prycom/remember-me/releases/download/test/remember-me-server).

```sh
chmod +x remember-me
./remember-me
```

Linux-клиент использует системные Opus, ALSA и PulseAudio (или PipeWire с совместимостью PulseAudio). Windows EXE содержит кодек и runtime; дополнительные DLL не нужны. Рекомендуется современный терминал с поддержкой Unicode и цвета. Если графический протокол терминала недоступен, картинки отображаются цветными символами.

## Своя комната

На сервере:

```sh
chmod +x remember-me-server
./remember-me-server -p 51900
```

Откройте выбранный **UDP**-порт в файрволе; в Docker также опубликуйте его как UDP. Серверный бинарник статический, аудиобиблиотеки ему не нужны.

В настройках клиента укажите `SERVER_IP:51900` и создайте комнату. Отправьте друзьям показанную строку `КОД@SERVER_IP:51900`. Подключиться можно через меню или командой:

```sh
./remember-me --connect КОД@SERVER_IP:51900
./remember-me --check-server SERVER_IP:51900
```

Порт выбирается при запуске сервера и должен совпадать с адресом у клиентов. Для прямого звонка: `remember-me --host`, затем `remember-me --connect HOST_IP:51500` на другом компьютере.

## Управление

| Клавиша | Действие |
| --- | --- |
| `F2` | Настройки, в том числе во время звонка |
| `i` / `Esc` | Ввод сообщения / выход из ввода |
| `←` / `→` при вводе | Перемещение курсора |
| `↑` / `↓`, `PgUp` / `PgDn` | Выбор и прокрутка истории |
| `Enter` на вложении | Просмотр скачанного файла |
| `Y` / `N` на предложении | Скачать / отказаться |
| `F3` | Предложить файл по пути |
| `Ctrl+V`, `Shift+Insert`, `F6` | Вставить текст или картинку из буфера |
| `m` / `d` | Микрофон / входящий звук |
| `Пробел` в PTT | Говорить, пока клавиша нажата |
| `O` в просмотрщике | Открыть исходный файл внешним приложением |
| `P`, `←` / `→` в GIF | Пауза / кадр назад или вперёд |
| `F5` | Проверить обновление |
| `?` | Справка |

По ссылкам, скачанным файлам и аватаркам можно нажимать мышью. Вставленная картинка сначала появляется как предложение отправки: `Enter` отправить, `Esc` отменить.

## Файлы приложения

| Данные | Linux | Windows |
| --- | --- | --- |
| Настройки | `$XDG_CONFIG_HOME/remember-me/config.toml` или `~/.config/remember-me/config.toml` | `%APPDATA%\remember-me\config.toml` |
| История чатов | `$XDG_STATE_HOME/remember-me/logs/` или `~/.local/state/remember-me/logs/` | `%LOCALAPPDATA%\remember-me\logs\` |
| Принятые файлы | Системная папка Downloads или путь из настроек | Downloads или путь из настроек |
| Вставленные картинки | Временная папка ОС или путь из настроек | Временная папка ОС или путь из настроек |

Новые снимки буфера удаляются при обычном выходе из приложения, а отменённая вставка — сразу. Принятые файлы сохраняются. При обновлении старая история переносится из папки конфигов; прежние постоянные снимки буфера сохраняются в `remember-me/attachments/` рядом с `logs/`, чтобы не потерять вложения. История хранится локально без шифрования.

Диагностика выводится в stderr; приложение не создаёт постоянный отладочный лог. При необходимости его можно записать самостоятельно: `RM_DEBUG=1 ./remember-me 2>remember-me.log`.

## Обновления

Клиент проверяет канал [GitHub Releases / test](https://github.com/Prycom/remember-me/releases/tag/test). Автопроверку можно отключить в настройках; ручная проверка — `F5` или `remember-me --update`. Проверяются платформа и SHA-256 сборки, затем заменяется **запущенный исполняемый файл**, независимо от текущей директории. Для применения нужно перезапустить клиент. Настройки и история сохраняются.

## Сборка

Нужен Rust stable. Зависимости для сборки Linux на Debian/Ubuntu:

```sh
sudo apt install libopus-dev libpulse-dev libasound2-dev pkg-config
cargo build --release --locked --bin remember-me
cargo test --locked
```

Сервер без клиентских зависимостей:

```sh
cargo build --release --locked --no-default-features --bin remember-me-server
```

Для статического сервера используйте target `x86_64-unknown-linux-musl`. Windows собирается с MSVC и CMake; готовые Linux/Windows-сборки и статический сервер публикует GitHub Actions.
